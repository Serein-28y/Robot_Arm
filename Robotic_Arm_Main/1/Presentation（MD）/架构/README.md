## 建议阅读顺序

1. `ARCHITECTURE.md` 第 1 章（一句话总览）→ 第 3 章（分层架构图）；
2. 第 5 章（启动流程）→ 第 6 章（主循环与任务节拍）；
3. 第 7 章（数据流：串口下行 / ACK 上行 / 按键 / OLED / 看门狗）；
4. 要动手改代码时：8.7 读码顺序 → 第 9 章"一次 MOVE 的完整链路"；
5. 卡在某个函数：第 13 章快速定位表，按"关键词 → 文件"查。
