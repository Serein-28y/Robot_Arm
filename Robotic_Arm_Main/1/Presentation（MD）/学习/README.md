## 一天怎么记（10 分钟，别超）

1. **先关代码**，把"今天的一条链"写出来：入口函数 → 关键分支 → 到硬件（哪个寄存器/引脚）。
2. 记 **3 个数字或结论**（能背下来的那种，比如"运动 20 ms 一步、时长夹在 300–2000 ms"）。
3. 记 **3 个没搞懂**，直接写成"明天第一件事"。
4. 只写**我做的判断和验证结果**；文档原文不要抄，抄了也记不住。

### "真懂了"的三条硬标准

- 合上代码能画出 MOVE 链路：`字节 → Command → 目标角 → current → us → CCR`；
- 给一个目标位姿，能手算 4 个 CCR（公式见清单 6.9 / 表 3-1）；
- 改一个参数能**先预测现象、再验证**（B 组那 5 个实验就是模板）。

## 每周复盘（周日 5 分钟）

把这一周每天的"第 3 节：数字/结论"抄成一张小表，只看三件事：

- 哪条链从"看懂"变成了"能讲出来"？
- 哪个参数改了之后能预测现象、且验证过？
- 哪些"没搞懂"连续出现 3 天以上 → 下周第一件事就做它。

## 文件命名
