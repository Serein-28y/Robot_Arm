# 机械臂工程文档（Presentation）

> 代码在仓库根的 `User/`、`tools/`、`docs/`；本目录只放"给人看"的文档。
> 一句话分工：**`架构/` 说明代码怎么组织，`学习/` 记录我懂到哪，`资料/` 放硬件与标定。**

## 目录

| 目录 | 内容 | 什么时候进 |
|---|---|---|
| [架构/](架构/README.md) | `ARCHITECTURE.md`：分层、依赖、启动/主循环、数据流、函数调用树、代码地图<br>`design_idea.md`：需求、详细设计、协议、参数、开发计划 | 想知道"这个函数为什么被调""当初为什么这么设计" |
| [学习/](学习/README.md) | `DAY1_学习清单与自检.md` + `每日记录/`（一天一页） | 每天学习、自测、写理解 |
| [资料/](资料/ARM_HANDOFF.md) | `ARM_HANDOFF.md`：接线、关节标定移交 | 上板前对引脚、对脉宽、对限位 |

## 三条阅读路线

1. **第一次通读**：`架构/ARCHITECTURE.md` 第 1 → 5 → 6 → 7 章（总览、启动流程、主循环、数据流），再进 `学习/DAY1_学习清单与自检.md`。
2. **要改代码**：`架构/ARCHITECTURE.md` 8.7 读码顺序 → 第 9 章"一条 MOVE 的完整链路" → 学习清单 §6「图 8：一条 Command 变成四路脉宽」+ 表 3-2 手算对照。
3. **每天 10 分钟**：`学习/每日记录/` 当天那页，模板是 [`_模板.md`](学习/每日记录/_模板.md)。

## 约定

1. `架构/` 只纠错、不复述学习过程；`学习/` 只写理解与验证，不整段抄文档。
2. **参数以代码为准**：`User/Inc/config/robot_params.h`。文档和代码打架时，先按代码验证，再把差异记进当天学习记录（已有的 5 处差异见学习清单 §10.3 表 4-2）。
3. 文中命令（`python tools/frame_tool.py ...`）都在仓库根 `Robotic_Arm_Main\1` 下执行。
4. 新增一天：复制 `学习/每日记录/_模板.md` → `DAYnn_YYYY-MM-DD.md`，并在 `学习/README.md` 的进度表加一行。
5. 交互自检页：`docs/0007-day1-check.html`（双击打开，分数和记录存本地浏览器）。
