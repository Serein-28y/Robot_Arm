# 机械臂舵机测试移交文档（ARM Handoff）

> 用途：为正式代码编写提供已标定的参数。
> 控制方式：PWM。舵机：众灵总线舵机（兼容 PWM，180° 规格）。

## 1. 硬件平台

| 项 | 值 |
|---|---|
| MCU | STM32F103C8T6 |
| 时钟 | HSE 8MHz，PLL×9 = 72MHz；APB1=/2，APB2=/1 |
| 工具链 | CMake + Ninja + arm-none-eabi-gcc |
| IDE | VS Code + STM32Cube 扩展；HAL |

## 2. PWM / 定时器

| 项 | 值 |
|---|---|
| 定时器 | TIM1（CH1–CH4） |
| Prescaler | 72-1 → 1MHz（1us/tick） |
| Period | 20000-1 → 20ms（50Hz） |
| 软件脉宽范围 | 500–2500us |

## 3. 舵机 / 通道 / 引脚映射

| 逻辑 | 名称 | 通道 | 代码索引 | 引脚 | pwm_min | pwm_max | home |
|---|---|---|---|---|---|---|---|
| Servo1 | 底座 BASE | CH4 | 3 | PA11 | 500 | 2500 | 1500 |
| Servo2 | 大臂 UPPER | CH3 | 2 | PA10 | 500 | 800 | 500 |
| Servo3 | 小臂 FOREARM | CH2 | 1 | PA9 | 500 | 1000 | 500 |
| Servo4 | 抓夹 GRIP | CH1 | 0 | PA8 | 500 | 2000 | 1500 |

## 4. 坐标系

- 从机械臂**后方看**为正方向建系；z 轴竖直向上，xy 为水平底面。
- 底座绕 z 轴在 xy 平面内旋转；大臂 / 小臂 / 抓夹在同一竖直平面内摆动。
- 底座实测：750us 时对准 **-x 轴**（180°）；500us 在 -x 的 -y 侧 22.5°，2500us 在 +x 的 +y 侧 22.5°。

## 5. 关节角度标定

| 关节 | 500us 姿态 | 2500us 姿态 | home | 方向 |
|---|---|---|---|---|
| 底座 BASE | xy 平面方位角 202.5°（距 -x 轴 22.5°，在 -y 侧） | 22.5°（距 +x 轴 22.5°，距 +y 67.5°） | 1500 | 脉宽↑ → 角度↓ |
| 大臂 UPPER | 相对 xy 平面 +45° 仰角（与 z 轴 45°） | −45° | 500 | 脉宽↑ → 仰角↓ |
| 小臂 FOREARM | 与大臂夹角 90°（最外侧） | — | 500 | 脉宽↑ → 向大臂收（夹角↓） |
| 抓夹 GRIP | 沿小臂方向 | — | 1500 | 脉宽↑ → 向小臂方向收 |

- home 姿态：底座 112.5°；大臂 +45° 仰角；小臂 与大臂夹角 90°；抓夹 沿小臂方向起算的中间位。

## 6. 角度换算公式（线性，us 单位）

| 关节 | 公式 | 校验 |
|---|---|---|
| 底座 | `θ = 202.5 − (us−500)·180/2000` | 500→202.5，750→180，1500→112.5，2500→22.5 |
| 大臂 | `θ = 45 − (us−500)·90/2000` | 500→+45，2500→−45 |
| 小臂 | `θ_肘 = 90 − k·(us−500)`，k 待定 | 方向：向大臂收 |
| 抓夹 | 斜率待定 | 500→沿小臂方向 |

> 小臂 / 抓夹目前只有**方向**，缺数值斜率；若正式代码只做“方向 + 限幅”控制，可暂不补。

## 7. 按键映射

| 按键 | 引脚 | 功能 |
|---|---|---|
| KEY1 | PB15 | 切换通道 1→2→3→4 |

## 9. 现有代码结构

- `main.c`：仅 `USER CODE BEGIN 2` 调 `Test()`；`while(1)` 空。
- `test.c`：规格表 `ServoSpec{name,pwm_min,pwm_max,range_deg}`；`SERVO_180`(默认) / `SERVO_270` 可切换；`servo_spec[4]`；`servo_home[4]={1500,500,500,1500}`；按键去抖 / 长按；OLED 界面。
- `CMakeLists.txt`：手写模块统一在工程根 `User/` 下，`target_include_directories` 增加 `User/Inc`，`USER_SOURCES` 列出 `User/Src/...`；`Core/Inc` 仍由 CubeMX 子目录提供。
